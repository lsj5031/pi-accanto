This is the source folder

Accanto needs bundled dependencies before it can run. In the project folder, use Node.js 22 or later and run:

npm ci
npm run build

Then remove this source copy at chrome://extensions, choose Load unpacked, and select the generated dist folder instead.

For a ready-built download, extract pi-accanto-VERSION.zip from a successful build's extension-download artifact, then load the folder containing manifest.json. GitHub's “Source code” ZIP is not an installable extension.
